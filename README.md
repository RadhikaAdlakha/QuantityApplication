# Quantity Measurement App

A full-stack Quantity Measurement application built using:

- Frontend: React
- Backend: Spring Boot
- Database: MySQL
- Build Tool: Maven

## Features

- Unit Conversion
- Arithmetic Operations
- Quantity Comparison
- REST APIs
- JWT Authentication

## Project Structure

QuantityMeasurementApp
├── frontend
├── backend

## Technologies Used

### Frontend
- React
- Axios
- CSS

### Backend
- Spring Boot
- Spring Security
- JPA/Hibernate
- Maven
